# 软件商店打不开、下载报错怎么办

【一句话结论】先分清是「打不开（一直转圈）」还是「下载报错（带错误码）」：打不开先清缓存，报错按码走对应分支。

【常见说法】应用商店、应用市场、商店打不开、装软件的地方、软件商店进不去、商店一直转圈、下载失败、下载没反应、点开是白的、商店闪退

【适用范围】银河麒麟桌面操作系统 V10 / V10SP1（全架构）

【按现象分四种情况】

## 情况一：点开一直转圈 / 打不开 / 闪退

清理当前用户的缓存与配置：

```bash
sudo rm -rf ~/.cache ~/.config
```

> 注意：该命令会删除当前用户主目录下所有缓存和配置文件，操作前请备份重要数据（浏览器收藏夹、密码等）。清理后重新登录或重启。

来源：《软件商店升级后，点击桌面快捷方式出现报错》问题解决方法、《获取最新版的软件商店》

## 情况二：下载时提示「空间不足」（错误码 #0007）

1. 先确认分区是不是真的满了：

```bash
df -Th
```

2. 若没有分区满，问题在用户缓存，仍然清理缓存：

```bash
sudo rm -rf ~/.cache ~/.config
```

来源：《软件商店下载安装软件时提示"下载失败，空间不足！（错误码#0007）"》问题解决方法

## 情况三：下载时提示「网络错误」（错误码 #0006）

外网正常但仍报网络错误，通常是 hosts 里有一条错误的解析记录。

1. 确认现象：

```bash
sudo apt-get update
telnet archive2.kylinos.cn 80
```

若 `apt-get update` 提示 80 端口拒绝连接，且 `telnet` 显示目标地址为 `127.0.0.1`，即可确认。

2. 编辑 hosts，注释掉那条错误记录：

```bash
sudo vim /etc/hosts
```

找到 `archive2.kylinos.cn` 指向 `127.0.0.1` 的那一行，在行首加 `#`。

来源：《软件商店下载软件提示网络错误0006》问题解决方法

## 情况四：卸载软件时提示错误码 #0004

用 dpkg 强制移除（解决依赖残留导致的无法卸载）：

```bash
sudo dpkg --remove --force-remove-reinstreq <包名>
```

来源：《软件商店卸载软件报错#0004》问题解决方法

【验证】

重新打开软件商店，能正常加载列表并完成一次下载，即恢复。

【相关】若是磁盘真正的分区满了（不是缓存问题），见《补充_磁盘空间不足.md》
