# 输入法切不出来、只能打英文怎么办

【一句话结论】先确认输入法框架 fcitx 是否正常；不行就重装 fcitx 和搜狗输入法，然后重启系统。

【常见说法】输入法切不出来、只能打英文、ctrl+shift 没反应、输入法图标不见了、打不出中文、输入法卡死

【适用范围】银河麒麟桌面操作系统 V10 / V10SP1（全架构），已安装搜狗输入法（sogouimebs）

【按现象分三种情况】

## 情况一：完全切不出中文（按 ctrl+shift 无反应、只能打英文）

重装 fcitx 与搜狗输入法，命令逐条执行：

```bash
sudo apt-get remove fcitx
sudo apt-get install -y fcitx
sudo apt-get remove sogouimebs
sudo apt-get install sogouimebs
```

执行完成后重启系统：
```bash
reboot
```

来源：《word 文档中无法切换输入法》问题解决方法

## 情况二：输入法能用，但右下角看不到状态栏

1. 打开「计算机」→「系统盘」，进入 `/opt/sogouimebs/files/bin` 目录
2. 双击运行 `SogouIme-configtool`（搜狗输入法配置工具）
3. 取消勾选「隐藏状态栏」，点击确定

来源：《搜狗输入法不显示状态栏》问题解决方法

## 情况三：输入法卡死、点了没反应

删除家目录下 .sogou 开头的隐藏文件夹：

```bash
sudo rm -rf ~/.sogou*
```

来源：《搜狗输入法卡死》问题解决方法
