# 电脑连不上网、网卡没起来怎么办

【一句话结论】先在终端执行 `ip a` 看网卡是否存在：没有网卡先查驱动（升级后常见 r8168-dkms 冲突），有网卡但没 IP 查 DHCP 配置。

【常见说法】连不上网、网卡没起来、网卡图标打叉、网络图标显示受限、上不了网、没网、获取不到 IP、ping 不通

【适用范围】银河麒麟桌面操作系统 V10 / V10SP1（全架构）；Realtek 系列网卡参见第一种情况

【按现象分四种情况】

## 情况一：系统升级后网卡不加载（`ip a` 里看不到网卡）

原因是 r8168-dkms 软件包顶替了内核自带的 r8169 驱动，两者冲突。

```bash
sudo apt remove --purge r8168-dkms
```

若提示卸载失败，改用强制卸载：

```bash
sudo dpkg -P r8168-dkms
```

然后重启：
```bash
reboot
```

注意：此方法仅针对 Realtek 系列网卡，已在 RTL8111E 上验证有效。
来源：《系统升级后网卡无法加载》问题解决方法

## 情况二：网卡在，但拿不到 IP（`ip a` 里没有 inet 地址）

编辑网卡配置文件，把 BOOTPROTO 改成 dhcp：

```bash
sudo vim /etc/sysconfig/network-scripts/ifcfg-<网卡名>
```

将 `BOOTPROTO` 的值改为 `dhcp`，保存后重启网络。
来源：《网络连接中无法自动获取 IP 地址》问题解决方法

## 情况三：能上网，但右下角网络图标显示「网络受限」

编辑 NetworkManager 配置，注释掉 connectivity 检查：

```bash
sudo vim /etc/NetworkManager/NetworkManager.conf
```

找到以下三行，在行首加 `#` 注释掉：

```
[connectivity]
uri=https://www.google.com
interval=45
```

保存后重启网络服务生效。
来源：《桌面右下角网络图标显示网络受限》问题解决方法

## 情况四：网络连接按钮是灰的，点不了

来源：《启用网络连接按钮置灰导致无法上网》问题解决方法 —— 该篇内容需在知识库中查看。

【验证】

```bash
ip a
ping -c 3 www.baidu.com
```

`ip a` 能看到网卡且状态 UP，`ping` 有回包，即恢复。
