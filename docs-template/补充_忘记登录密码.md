# 银河麒麟桌面操作系统V10【忘记登录密码】重置方法

【问题描述】

忘记系统登录密码，无法登录桌面。常见说法：忘记密码、忘记登录密码、忘记开机密码、登录密码忘了、密码错误进不去桌面、进不去系统、**忘记密码但不想重装系统、想保留原来的数据**。

【问题解决方法】

1、开机进入 grub 界面，按"e"键编辑 grub，在以 linux 开头这行 security= 前，添加"init=/bin/bash console=tty0"参数，然后按"F10"键保存启动，稍等片刻后，进入系统的单用户模式。

2、在单用户模式下，运行如下命令，给 root 账号设置一个密码：

```
passwd root
```

3、再运行如下命令，新建一个普通用户，再将该普通用户添加到 sudo 组，使其拥有管理员权限：

```
adduser [用户名]
usermod -a -G sudo [用户名]
```

4、最后，运行如下命令，重启系统：

```
/sbin/reboot -f
```

【数据会不会丢】

上述步骤只做两件事：给 root 设置密码、新建一个普通用户。**不涉及格式化分区、不涉及删除用户目录**，原来用户主目录（/home/原用户名）下的文件仍在原处。

如果原来的普通用户还在，改完密码后直接用原用户名登录即可，文件都在。
如果不确定原用户是否还在，进单用户模式后先看一眼：

```
ls /home
```

- 只是**忘记密码** → 按本文处理
- 账号被**误删**了 → 需要先恢复账号，见知识库《银河麒麟桌面操作系统V10（ARM）【误删管理员账号】问题解决方法》
