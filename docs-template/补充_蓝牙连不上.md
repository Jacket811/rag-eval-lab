# 蓝牙连不上、搜不到设备、蓝牙耳机没声音怎么办

【一句话结论】先 `rfkill list` 看蓝牙是否被开关关掉，再 `systemctl status bluetooth` 看服务是否在跑；服务是 dead 就重启它。

【常见说法】蓝牙连不上、蓝牙搜不到设备、搜索蓝牙一直转圈、蓝牙耳机连不上、蓝牙耳机没声音、蓝牙配对失败、蓝牙图标不见了、蓝牙模块消失、显示 BlueZ 守护进程没有运行

【适用范围】银河麒麟桌面操作系统 V10 / V10SP1（全架构）

## 第一步：确认蓝牙开关没被关掉

```bash
rfkill list
```

看输出里蓝牙那一项的 `Soft blocked` / `Hard blocked` 是否为 `yes`。

开启（把编号 0 换成实际编号）：

```bash
rfkill unblock 0
```

关闭用 `rfkill block 0`。
来源：《桌面通用(全架构)【手动关闭和开启蓝牙模块】操作方法》

## 第二步：确认蓝牙服务在运行

```bash
systemctl status bluetooth.service
```

若 `Active` 处显示 `inactive (dead)`，说明蓝牙服务异常，重启：

```bash
sudo systemctl restart bluetooth.service
```

这是"打开蓝牙后搜索不到设备、一直转圈"最常见的原因。
来源：《桌面通用(全架构)【打开蓝牙后搜索不到蓝牙设备】问题解决方法》

## 第三步：按现象分流

| 现象 | 该看哪篇 |
|---|---|
| 搜不到任何设备、一直转圈 | 本篇第二步（重启 bluetooth 服务） |
| 提示 BlueZ 守护进程没有运行 | 《蓝牙连接不上，显示BlueZ守护进程没有运行》 |
| 笔记本上蓝牙模块直接消失 | 《长城 TN140A2 笔记本上蓝牙模块消失》 |
| 长城笔记本提示蓝牙驱动异常 | 《长城笔记本蓝牙驱动异常》——左侧飞行模式开关下的按键 |
| 想确认设备是否已配对 | `bluetoothctl paired-devices` 列出已配对设备 |

## 第四步：验证

```bash
bluetoothctl paired-devices
```

能列出已配对设备，或在「设置 → 蓝牙」里能搜到并连上耳机，即恢复。
