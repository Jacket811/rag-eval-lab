# 系统盘/磁盘空间不足怎么办（含软件商店提示"空间不足 0007"）

【一句话结论】先用 `df -Th` 确认哪个分区满了；软件商店报 0007 但分区没满时，是用户缓存/配置占爆，清 `~/.cache` 和 `~/.config`。

【常见说法】磁盘满了、系统盘满了、空间不足、可用空间不足、软件商店下载失败、安装软件提示空间不足、错误码0007、更新失败、C盘满了

【适用范围】银河麒麟桌面操作系统 V10 / V10SP1（全架构）

## 情况一：软件商店下载安装提示"下载失败，空间不足！（错误码#0007）"

1. 先确认分区是否真的满：

```bash
df -Th
```

2. 如果分区未满但报 0007，说明是当前用户的缓存和配置占用过大，清理：

```bash
sudo rm -rf ~/.cache ~/.config
```

> ⚠️ 注意：该命令会删除当前用户主目录下的所有缓存和配置文件，操作前请备份重要数据（浏览器收藏夹、密码等）。

来源：《银河麒麟桌面操作系统V10(全X86/ARM架构)【软件商店下载安装软件时提示"下载失败，空间不足！（错误码#0007）"】问题解决方法》

## 情况二：分区确实满了，找不出是谁占的

先看整体用量：

```bash
df -Th
```

再逐层看哪个目录大（通用排查方法，非本文档库原文）：

```bash
sudo du -h --max-depth=1 / | sort -h
```

找到大目录后进入该目录，重复上面这条命令，一层层往下定位，直到找到占用最大的文件，再决定是转移到数据盘还是删除。

来源：《桌面通用(全架构)【系统盘或数据盘容量显示差异】问题解决方法》提到的 df 查看方式

## 情况三：df 显示的容量和 lsblk 不一样

这是正常现象，不用处理：

- `df` / 文件管理器显示的是**文件系统层面可用容量**（已扣除文件系统元数据、保留空间）
- `lsblk` 显示的是**块设备总容量**（扇区数 × 扇区大小）
- 因此 lsblk 通常比 df 显示得更大

来源：《桌面通用(全架构)【系统盘或数据盘容量显示差异】问题解决方法》

【验证】

```bash
df -Th
```

根分区（/）可用空间大于 1G，且软件商店能正常下载安装，即处理完成。
