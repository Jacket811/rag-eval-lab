# 屏幕字太大改不小、开机直接进 Windows 怎么办

【一句话结论】分辨率问题用 `xrandr` 临时改（重启失效）；双系统默认启动项改 `/etc/default/grub` 里的 `GRUB_DEFAULT`。

【常见说法】字特别大、字太小、屏幕分辨率不对、分辨率改不了、调不了分辨率、屏幕显示不正常、显示器不被识别、开机直接进Windows、进不去麒麟、默认启动项不对、开机没有选择菜单

【适用范围】银河麒麟桌面操作系统 V10 / V10SP1（全架构）

【按现象分两种情况】

## 情况一：屏幕字特别大 / 分辨率不对 / 调不了

1. 先看当前支持哪些分辨率：

```bash
xrandr
```

2. 临时切换（立即生效）：

```bash
xrandr -s 1920x1080
```

> 注意：`xrandr -s` 改的是当前会话，**重启后会失效**。要永久生效需修改显示配置文件或通过 grub 参数设置。

来源：《修改当前显示器分辨率的命令》

## 情况二：装完双系统，开机直接进 Windows，进不去麒麟

改 grub 的默认启动项。

1. 编辑 grub 配置：

```bash
sudo vim /etc/default/grub
```

2. 找到这一行：

```
GRUB_DEFAULT=0
```

`GRUB_DEFAULT` 定义默认启动项，`0` 代表 grub 菜单里的第一个（通常是银河麒麟）。要改成第三个菜单项就写 `2`：

```
GRUB_DEFAULT=2
```

3. 保存后更新 grub：

```bash
sudo update-grub
```

来源：《双系统启动顺序设置》操作方法

【验证】

- 分辨率：`xrandr` 输出里的当前分辨率已变为目标值
- 启动项：重启后 grub 默认选中项已指向目标系统
